Step 1: Self-Attention - Words Looking at Words

What's Happening?

Each word in a sentence looks at every other word to understand context. Click on any word below to see which other words it "pays attention to" - brighter colors mean stronger attention!

Technical Details

Self-attention computes Attention(Q,K,V) = softmax(QK^T/√d_k)V. Each token generates query, key, and value vectors. The attention weights show how much each token attends to others. This enables capturing long-range dependencies in O(1) steps.

Step 2: Query, Key, Value - The Attention Mechanism

What's Happening?

Think of attention like a search engine: the Query is what you're searching for, Keys are like titles of documents, and Values are the actual content. The model matches queries to keys to find relevant values!

Technical Details

For input X, we compute Q=XW^Q, K=XW^K, V=XW^V where W matrices are learned. Attention scores are QK^T (dot product similarity), scaled by √d_k to prevent gradient issues, then softmaxed to get weights that sum to 1.

Step 3: Multi-Head Attention - Multiple Perspectives

What's Happening?

Instead of one attention pattern, transformers use multiple "heads" that each focus on different aspects. One head might focus on grammar, another on meaning, another on position. Together they capture rich relationships!

Technical Details

MultiHead(Q,K,V) = Concat(head_1,...,head_h)W^O where each head_i = Attention(QW_i^Q, KW_i^K, VW_i^V). Typical models use 8-96 heads. Each head has dimension d_k = d_model/h, maintaining total computation.

Head 1: Positional Attention

This head tends to attend to nearby words, capturing local context and phrase structure.

Step 4: The Full Transformer

What's Happening?

A transformer stacks multiple layers of attention and processing. Data flows through: Embedding → Multiple Transformer Blocks → Output. Each block refines the understanding. Watch the data flow through the architecture!

Technical Details

Each transformer block: x = LayerNorm(x + MultiHeadAttention(x)), then x = LayerNorm(x + FFN(x)). The FFN is typically two linear layers with GELU activation. Residual connections enable gradient flow in deep networks (12-96 layers).
