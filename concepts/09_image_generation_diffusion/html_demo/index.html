Image Generation & Diffusion

Creating images from noise

Step 1: The Diffusion Process

What's Happening?

Diffusion models learn by adding noise to images until they become random static, then learning to reverse the process. Watch an image get noisy, then see it restored!

Technical Details

Forward process: q(x_t|x_{t-1}) adds Gaussian noise over T steps. Reverse process: p_θ(x_{t-1}|x_t) learns to denoise. The model predicts noise ε at each step, trained with MSE loss: L = ||ε - ε_θ(x_t, t)||².

Step 2: Text-to-Image Generation

What's Happening?

Your text prompt guides the denoising process. The AI starts with random noise and gradually shapes it into an image matching your description. Watch the generation unfold!

Technical Details

Text is encoded via CLIP/T5 into embeddings. Cross-attention layers condition the U-Net on these embeddings. Classifier-free guidance: ε̃ = ε_uncond + s(ε_cond - ε_uncond) controls prompt adherence.

Step 3: Generation Parameters

What's Happening?

Different settings affect the final image. Guidance scale controls how closely the AI follows your prompt. Steps affect quality. Seed determines the random starting point.

Technical Details

Guidance scale (s) in CFG: higher values increase prompt adherence but may reduce diversity. More steps improve quality but with diminishing returns. Same seed + prompt = reproducible results.

Step 4: Latent Diffusion

What's Happening?

Modern diffusion models work in a compressed "latent space" instead of pixel space. This makes generation much faster while maintaining quality. See how images are compressed and reconstructed!

Technical Details

VAE encoder compresses 512×512×3 images to 64×64×4 latents (48× smaller). Diffusion happens in latent space. VAE decoder reconstructs pixels. This enables high-res generation on consumer GPUs.
