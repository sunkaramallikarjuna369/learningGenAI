Step 1: The Single Neuron

What's Happening?

A single neuron is like a tiny decision-maker. It receives multiple inputs, weighs their importance, adds them up, and decides whether to "fire" (output a signal) or not. Click the inputs below to see how changing them affects the output!

Technical Details

A neuron computes y = f(Σ(w_i × x_i) + b), where x_i are inputs, w_i are weights, b is bias, and f is an activation function. The activation function introduces non-linearity, enabling the network to learn complex patterns.

Step 2: Building a Network

What's Happening?

When we connect many neurons in layers, we get a neural network! Data flows from left to right: the input layer receives data, hidden layers process it, and the output layer gives the final answer. Watch the signal flow through the network!

Technical Details

This is a feedforward network (MLP). Each layer computes a = g(Wa + b), where W is the weight matrix, a is the previous layer's activations, b is the bias vector, and g is the activation function. The network learns by adjusting W and b via backpropagation.

Step 3: How Networks Learn

What's Happening?

Neural networks learn by making predictions, comparing them to correct answers, and adjusting their weights to do better next time. It's like practicing a skill - you get feedback and improve! Watch the error decrease as the network learns.

Technical Details

Training uses gradient descent: weights are updated as w = w - η∇L, where η is the learning rate and ∇L is the gradient of the loss function. Backpropagation efficiently computes gradients using the chain rule. The loss decreases over epochs as the network converges.

Step 4: Activation Functions

What's Happening?

Activation functions decide whether a neuron should "fire" or not. Without them, neural networks could only learn simple straight-line patterns. Different functions have different behaviors - try them out!

Technical Details

Activation functions introduce non-linearity. ReLU(x) = max(0,x) is most common due to computational efficiency and avoiding vanishing gradients. Sigmoid σ(x) = 1/(1+e^-x) outputs (0,1), useful for probabilities. Tanh outputs (-1,1) and is zero-centered.
