# 17 - GenAI in Non-IT Roles

## Overview

Generative AI isn't just for developers - it's transforming how professionals across all industries work. From teachers creating lesson plans to marketers writing campaigns, HR managers screening candidates, and executives preparing reports, GenAI is becoming an essential productivity tool for everyone.

---

## For Non-Technical Readers

### Who Can Use GenAI?

**Everyone!** You don't need to know how to code to benefit from AI. If you can type a question or describe what you need, you can use GenAI.

### Common Roles Using GenAI

**Teachers & Educators:**
- Create lesson plans and quizzes
- Generate explanations at different levels
- Develop personalized learning materials
- Grade and provide feedback

**Marketing & Communications:**
- Write blog posts and social media content
- Create email campaigns
- Generate ad copy variations
- Develop brand messaging

**Human Resources:**
- Write job descriptions
- Screen resumes
- Create interview questions
- Draft policies and handbooks

**Sales:**
- Write personalized outreach emails
- Create proposals and presentations
- Summarize customer calls
- Research prospects

**Finance & Accounting:**
- Generate reports and summaries
- Analyze data and trends
- Create documentation
- Draft communications

**Legal:**
- Review and summarize contracts
- Research case precedents
- Draft standard documents
- Analyze compliance requirements

**Healthcare Administration:**
- Create patient communications
- Summarize medical literature
- Generate documentation
- Develop training materials

### How to Get Started

1. **Choose a Tool:** ChatGPT, Claude, Gemini, or Copilot
2. **Start Simple:** Ask it to help with a routine task
3. **Be Specific:** The more detail you provide, the better the output
4. **Iterate:** Refine the output by asking for changes
5. **Review:** Always check AI output before using it

### Tips for Non-Technical Users

- **Think of AI as a first draft generator** - it gives you a starting point
- **Be specific about your audience** - "explain for a 5th grader" vs "explain for experts"
- **Ask for alternatives** - "give me 3 different versions"
- **Request specific formats** - "as a bullet list" or "in a table"
- **Provide examples** - show what you want the output to look like

### Prompt Engineering for Domain Experts

**Role-Based Prompting:**
```
You are an experienced HR manager at a Fortune 500 company.
Help me write a job description for a Senior Marketing Manager
that emphasizes our commitment to work-life balance.
```

**Template-Based Workflows:**
```
Create a [document type] for [audience] that includes:
- [required element 1]
- [required element 2]
Tone: [formal/casual/professional]
Length: [word count or format]
```

| Role | Task | Time Before | Time After | Improvement |
|------|------|-------------|------------|-------------|
| Teacher | Lesson plan | 2 hours | 30 min | 75% |
| Marketer | Blog post | 4 hours | 1 hour | 75% |
| HR | Job description | 1 hour | 15 min | 75% |
| Sales | Outreach email | 30 min | 5 min | 83% |

### Common Challenges

**Quality Control:**
- AI may generate plausible but incorrect information
- Domain expertise needed to verify accuracy
- Establish review processes

**Consistency:**
- Output varies between sessions
- Use templates and examples for consistency
- Save successful prompts for reuse

**Privacy:**
- Don't input sensitive data into public AI tools
- Use enterprise versions with data protection
- Understand data retention policies

## Role-Specific Examples

### Teacher Example

**Task:** Create a quiz on photosynthesis for 8th graders

**Prompt:**
```
Create a 10-question quiz on photosynthesis for 8th grade students.
Include:
- 5 multiple choice questions
- 3 fill-in-the-blank questions
- 2 short answer questions
Make questions progressively harder.
Include an answer key at the end.
```

### Marketing Example

**Task:** Write social media posts for a product launch

**Prompt:**
```
Write 5 social media posts announcing our new eco-friendly water bottle.
Target audience: environmentally conscious millennials
Platforms: Instagram, Twitter, LinkedIn
Key features: BPA-free, 24-hour insulation, made from recycled materials
Tone: Enthusiastic but not pushy
Include relevant hashtags for each platform.
```

### HR Example

**Task:** Create interview questions

**Prompt:**
```
Generate 10 behavioral interview questions for a Customer Success Manager position.
Focus on:
- Problem-solving skills
- Communication abilities
- Customer empathy
- Conflict resolution
Include follow-up probing questions for each.
```
